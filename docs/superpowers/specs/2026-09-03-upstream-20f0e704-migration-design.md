# 上游 20f0e704 优化移植设计

## 目标

将上游提交 `20f0e704be5ec613937a31afc65811db1451c59a` 中的全部功能优化移植到当前项目，同时保留当前项目已有的首页布局、`HomePortfolioShutter`、导航生命周期和响应式表现。

## 不迁移内容

- 不删除当前项目已有组件或页面。
- 不删除上游提交中的历史设计文档。
- 不直接覆盖当前项目与上游结构不一致的首页和生命周期文件。
- 不改变首页现有卡片尺寸、定位、动画时序和移动端布局，除非为图片加载增强所必需。

## 当前项目约束

- 首页包含 `HomeHero`、`HomeTicker`、`HomeDataLayer`、`HomeBlinds`、`HomePortfolioShutter` 和 `HomeMobile`。
- 当前项目使用 `src/utils/home-lifecycle.ts` 管理首页模块生命周期。
- 当前项目使用 `src/utils/swup-lifecycle.ts` 管理 Swup 孤岛和导航事件，但没有上游新增的 `layout-init.ts`。
- 当前项目通过 `src/styles/main.css` 合并全局和页面相关样式，Astro 配置当前为 `cssCodeSplit: false`。

## 功能设计

### 1. 首页 Lenis 平滑滚动

- 添加 `lenis` 依赖。
- 新增或适配首页平滑滚动控制器，通过当前 `home-lifecycle` 的 `boot` / `teardown` 接口挂载。
- 只在桌面宽度、精确指针设备且未启用 `prefers-reduced-motion` 时启用。
- 使用已有 GSAP `ScrollTrigger`，将 Lenis 帧更新与 GSAP ticker 同步，并在滚动事件中刷新 ScrollTrigger。
- 导航离开首页、断点切换和 HMR 时销毁实例、移除监听，防止重复 rAF 和残留状态。
- 不改变移动端原生滚动和当前首页 DOM 层级。

### 2. CSS 按页拆包与 Swup 预取

- 将 `astro.config.mjs` 的 `cssCodeSplit` 改为 `true`。
- 以当前项目的 CSS 组织方式为准，确认布局基础样式、导航样式、常驻组件样式仍保持全局；页面专属样式按页面引入。
- 对首页现有显式 CSS 引入保持兼容，避免拆包后首页首屏缺少样式。
- 新增 Swup CSS 预取模块，在目标页面预载 HTML 后解析同源 stylesheet，并以不影响当前屏幕渲染的方式提前加载。
- 预取逻辑使用 DOM API 安全匹配 href，避免未转义 URL 直接拼接到 CSS selector 引发异常。
- 预取属于性能增强，失败时不阻断正常导航。
- 预取模块通过当前项目的常驻生命周期只安装一次。

### 3. 首页封面图优化

- 复用当前项目已有的 `buildCoverImage`、`processCoverImageSync`、`CoverImage` 或等效图片工具。
- 为固定文章卡片和最近文章卡片提供响应式图片源、LQIP 占位和懒加载。
- 保留当前卡片的外层结构、定位、尺寸和文字层级。
- 图片缺失或处理失败时保留原有无图渲染路径，不产生空白布局或尺寸跳变。
- 依据当前首页实际卡片宽度设置 `widths` 和 `sizes`，不套用与当前布局不匹配的上游固定值。

### 4. 语义和主题样式修复

- 搜索弹窗增加 Lenis 兼容标记，仅用于阻止平滑滚动与弹窗滚动冲突。
- 音乐播放器标题采用合适的语义标签，同时保留现有视觉样式。
- 移植工具卡片描述、链接和 `strong` 在暗色模式下的颜色适配。
- 所有颜色调整以当前主题变量和现有选择器为准，避免覆盖当前项目定制色。

## 验证标准

- `pnpm type-check` 或项目等效类型检查通过。
- `pnpm test` 通过，已有测试不因生命周期或滚动初始化改变而回归。
- `pnpm build` 成功，且生成的页面能够加载所需 CSS。
- 桌面端首页启用 Lenis；移动端、触屏设备和减少动态效果设置下保持原生滚动。
- 首页现有视觉布局、文章卡片位置、首页动画和移动端结构不发生明显变化。
- 从首页导航到其他页面、再返回首页时，滚动控制器和页面样式均能正确恢复且不重复注册。

## 实施边界

实现只涉及完成上述四组功能所需的依赖、配置、生命周期、首页组件、样式和测试调整；不进行无关重构、依赖升级、文档清理或布局重设计。
